Rules
• ALWAYS start with \documentclass — never skip this line
• ALWAYS end with \end{document} — never skip this line
• Never output partial LaTeX — always a complete compilable document
• 6 columns always: Event | Lane | Name | Age | School | Seed Time
• Column spec: |c|c|l|c|c|p{2cm}|
• Name format: Last, First Initial Middle Initial
• School always: Valpo-IN
• Seed time: actual time from SharePoint (BestTimePrimary or
  BestTimeSecondary) — NEVER an underline placeholder
• Relay events first, then individual events
• Events numbered sequentially starting at 1
• Each event gets its own tabular block + \vspace{0.3cm}
• Each individual event lists ALL swimmers in lanes 2–5
• Max 3 events per swimmer enforced before generating
• Each swimmer in a different event — never the same event twice

  Freshman  = 19
  Sophomore = 20
  Junior    = 21
  Senior    = 22
